# RustyCode

RustyCode is a lightweight, fast, and cross-platform code editor written in Rust.

## Features
- 🌍 **Multi-language Support** (English, Русский, 中文, Español, Deutsch, Français)
- 🚀 **Fast & Native** (powered by `egui`)
- 💻 **Built-in Terminal** (execute your Python/Rust/C++ scripts directly)
- 📂 **File Explorer** (navigate project files seamlessly)
- 🎨 **Syntax Highlighting** & **Smart Auto-indentation**
- 🔍 **Dynamic Zooming** (Scale UI up and down without breaking)

## Getting Started

Make sure you have [Rust](https://www.rust-lang.org/tools/install) installed on your system.

```bash
# Run the editor
cargo run --release
```
